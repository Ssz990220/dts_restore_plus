DTS Enabler PCM multichannel — experimental LG C5 test build 2.7.53

Fork: https://github.com/Ssz990220/dts_restore_plus
Original credits and licenses are retained.

This candidate preserves the prior DTS 5.1 MAT path and adds a separate
Moonfin PCM 7.1 route. TrueHD/MLP/DTS software-decoded, positioned 8-channel
48 kHz PCM receives explicit native layout metadata without enabling the
LG switch that was observed to collapse the layout to 5.1. Only after
native 8-channel/acmod21 sink and converter proof can the controller request
plain LPCM 7.1. Opus 7.1 in Moonfin uses the same guarded output request.

This candidate is NOT yet validated on the TV. The previous temporary Opus
probe reached Sonos PCM 7.1, with provisional listening confirmation; that
does not validate this new TrueHD/DTS code or every physical speaker position.
E-AC3/DDP 7.1 hardware decoding remains outside the new routing policy.
No movie audio is converted to Opus by this patch.

Installing replaces the existing DTS Enabler app ID. Applying its payload
requires stopping playback and pressing Enable. Keep eARC On, Digital Sound
Out Auto, and the opt-in multichannel PCM test enabled. Restart the video.
Test all eight positions, including center/LFE and side versus rear surrounds.
A receiver badge alone is insufficient. Do not compensate Mac channel mapping
in this build; this candidate targets TV-internal Moonfin playback only.

Keep the previous 2.7.52 test IPK for rollback. Stop playback, disable the
PCM test, reinstall the previous package and press Enable to restore its
payload. Do not run two route controllers concurrently.

No credentials, user movie samples or authenticated stream URLs are included.
